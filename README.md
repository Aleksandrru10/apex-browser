# 🚀 Apex Browser
> **Персональный настольный браузер нового поколения, объединяющий лучшие возможности Arc, Microsoft Edge, Mozilla Firefox и Google Chrome, с мощным движком неограниченных изолированных профилей.**

---

## 🌟 Синтез лучших браузерных возможностей

### 1. 🟣 Из Arc Browser:
* **Пространства (Spaces)**: Независимые рабочие зоны (Общее, Разработка, Медиа, Трейдинг) с персональными цветами, иконками и раздельными наборами вкладок.
* **Командная палитра (`Ctrl+K` / `Ctrl+T`)**: Spotlight-панель быстрого поиска и переключения между открытыми вкладками любых пространств, историей, закладками и встроенными функциями.
* **Закрепленные приложения (Pinned Favorites)**: Верхний док избранных веб-сервисов (YouTube, GitHub, Google, ChatGPT, Telegram).
* **Быстрый предпросмотр (Arc Peek)**: Всплывающая карточка для мгновенного просмотра ссылок без перехода со страницы (с возможностью развернуть в полноценную вкладку).
* **Быстрые заметки (Easel)**: Встроенный блокнот для сохранения мыслей, ссылок и выжимок во время серфинга с автосохранением на диск.

### 2. 🔵 Из Microsoft Edge:
* **Вертикальные вкладки**: Удобная боковая панель вкладок со звуковыми индикаторами воспроизведения аудио и кнопкой сворачивания в компактный док.
* **Спящие вкладки (Sleeping Tabs / RAM Optimizer)**: Автоматическая и ручная заморозка фоновых вкладок для высвобождения до 80% оперативной памяти. Вкладка моментально оживает при клике.
* **Разделение экрана (Split Screen, `Alt+S`)**: Просмотр двух страниц бок о бок в одном окне с интерактивным ползунком регулировки ширины и возможностью менять вкладки местами.
* **Утилитарная правая панель (Edge Sidebar)**:
  - 🤖 **AI-помощник (Copilot)**: Встроенный диалоговый ассистент.
  - 📝 **Заметки**: Полноценный блокнот.
  - 📱 **QR-код текущей страницы**: Мгновенная передача ссылки на смартфон через сканирование камерой.
  - 📥 **Менеджер загрузок**: Скорость, прогресс, пауза, показ в папке.
  - ⭐ **Закладки и история**.

### 3. 🟠 Из Mozilla Firefox:
* **Полная изоляция контейнеров**: Каждому профилю выделяется независимое хранилище куки, кеша, LocalStorage и IndexedDB (`persist:profile_<id>`).
* **Защита от слежения и рекламы (Apex Shield)**: Блокировка трекеров аналитики, рекламных баннеров, криптомайнеров и сборщиков отпечатков.
* **Режим чтения (Reader Mode)**: Очистка страницы от баннеров и верстки с настройкой размера шрифта, семейств (Serif / Sans) и цветовых схем (Темная, Сепия, Светлая).
* **Приватные заголовки**: Автоматическая отправка `DNT: 1` (Do Not Track) и `Sec-GPC: 1` (Global Privacy Control).

### 4. 🔴 Из Google Chrome:
* **Ядро Chromium (V8)**: Молниеносная скорость загрузки, полная поддержка HTML5, WebGL, WebAssembly и медиа-потоков.
* **Умный Omnibox**: Живые поисковые подсказки от Google, распознавание доменов, замок SSL-сертификата.
* **Копирование чистой ссылки (Clean Link)**: Автоматическое удаление трекинговых меток (`utm_*`, `fbclid`, `gclid`) в один клик.
* **Полноценный менеджер закладок и загрузок**.

## 👥 Движок мультипрофилей (Multi-Profile Engine)

Вы можете создавать **неограниченное количество профилей** для работы, личных дел, криптобирж, арбитража или мультиаккаунтинга:
* **Имя, аватарка (Emoji) и цветовая тема**.
* **Персональный HTTP/HTTPS/SOCKS5 прокси** с авторизацией по логину и паролю.
* **Кастомный User-Agent** (Chrome Win11, Safari macOS, Firefox Linux, iPhone).
* **Изолированный контейнер сессии**: логины в аккаунты одного профиля никак не пересекаются с другими.
* Клонирование профилей, мгновенное переключение в один клик и очистка данных.

## ⌨️ Горячие клавиши (Shortcuts)

| Сочетание клавиш | Действие |
| :--- | :--- |
| `Ctrl + T` | Открыть новую вкладку |
| `Ctrl + W` | Закрыть текущую вкладку |
| `Ctrl + K` | Открыть командную палитру (Command Palette) |
| `Alt + S` | Включить / выключить разделение экрана (Split Screen) |
| `Ctrl + Shift + M` | Открыть менеджер профилей |
| `Ctrl + R` / `F5` | Перезагрузить страницу |
| `Alt + Left` | Назад в истории |
| `Alt + Right` | Вперед в истории |
| `F12` | Открыть инструменты разработчика (DevTools) |
| `Escape` | Закрыть любое модальное окно или предпросмотр |

## 🚀 Запуск браузера

Для запуска достаточно дважды кликнуть по файлу:
👉 **`Запустить Apex Browser.bat`** (в корне `d:\Codex` или `d:\Codex\apex-browser`).

Или из командной строки:
```bash
cd D:\Codex\apex-browser
npm start
```

Для режима разработчика с горячей перезагрузкой:
```bash
npm run dev
```

Для запуска тестов:
```bash
npm test
```

## 🔑 Импорт паролей из других браузеров и автозаполнение

В Apex Browser встроен полноценный менеджер паролей с возможностью миграции из существующих браузеров:

### Как экспортировать пароли из старого браузера:
1. **Google Chrome**: Настройки (`chrome://password-manager/passwords`) ➔ Настройки слева ➔ «Экспорт паролей» ➔ «Скачать файл» (`.csv`).
2. **Microsoft Edge**: Параметры (`edge://settings/passwords`) ➔ Меню с тремя точками `...` рядом с заголовком ➔ «Экспорт паролей» ➔ Сохранить `.csv`.
3. **Mozilla Firefox**: Меню ➔ «Пароли» (`about:logins`) ➔ Меню с тремя точками `...` справа вверху ➔ «Экспортировать логины» ➔ Сохранить `.csv`.

### Как импортировать в Apex Browser:
1. Нажмите иконку **ключа 🔑** в правой части адресной строки (Omnibox) или перейдите в **Командную палитру (`Ctrl+K`) ➔ Менеджер паролей**.
2. Нажмите синюю кнопку **«Импорт из файла (.csv)»**.
3. Выберите скачанный `.csv` файл. Все пароли моментально импортируются и привяжутся к доменам!

### Автозаполнение:
* При входе на сайт (например, `vk.com`, `github.com`, `youtube.com`) иконка ключа в адресной строке покажет бейдж с количеством сохраненных аккаунтов.
* Нажмите на значок ключа или кнопку **«Заполнить»** в списке — логин и пароль автоматически подставятся в форму авторизации на странице!
